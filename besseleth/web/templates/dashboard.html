Contacts

Import from LinkedIn

LinkedIn has no API for pulling your connections into a third-party app — there's no live sync to offer here. What LinkedIn does let you do: export them yourself as a CSV (Settings & Privacy → Data privacy → "Get a copy of your data" → check Connections → request archive; LinkedIn emails a download link, sometimes after a delay). Upload that CSV here for a one-time bulk import — name, email, LinkedIn URL, and current company/title get filled in automatically (it has no education data, so schools still need adding by hand). Safe to re-upload later; already-added contacts are skipped.

Industry

The single most load-bearing setting in besseleth — keywords drive every paper/news/event search. Be specific; broad single words flood the report with noise. Takes effect on the next fetch/enrich, no restart.

Schedule

How often besseleth fetches fresh items, and when it renders the weekly report — only matters if the schedule is enabled (see schedule.enabled in config.yaml; there's no toggle for that here since disabling it mid-run doesn't stop a fetch/report already in flight). Changes re-arm the running schedule immediately.

Report cron is a standard 5-field cron expression (minute hour day-of-month month day-of-week), e.g. "0 4 * * MON" = 4am every Monday. Leave timezone blank to use this host's local time.

Data maintenance

Citation counts and stock prices are only ever fetched once, when the item/company is first seen — nothing re-checks them automatically after that, so a paper's real citation count (which only ever grows) or a company's stock price can go stale. Free, safe to re-run any time.

Tabs

Hide the tabs you don't use — this is per-browser (saved locally), so it doesn't affect anyone else viewing this dashboard. "Report" and "Settings" itself always stay visible.

LLM backend

Which LLM does enrichment/summarization — extracting orgs, metrics, novelty, writing report sections, comparing an uploaded paper against existing research. This is a server-wide setting (saved to config.yaml), not per-browser.

Get a free Groq API key at console.groq.com, or set it via the GROQ_API_KEY environment variable instead of storing it here. Ollama needs Ollama installed and running on this machine.
